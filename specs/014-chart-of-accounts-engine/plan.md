# Implementation Plan: Chart of Accounts Engine (014)

**Branch**: `feat/chart-of-accounts-engine` | **Date**: 2026-08-01 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/014-chart-of-accounts-engine/spec.md`

## Summary

Add a **Chart of Accounts Engine** in backend domain/application that owns structural catalog mutations (`create`, `rename`, `reparent`, `recode`, `deprecate`) with **dry-run**, **cascade recode**, class-digit invariants, and audit. Evolve admin `CuentaGlobal` HTTP + `admin-ui` into clients of this engine. Chart releases (Phase 2) are designed via op schema but **not implemented** in 014 MVP.

## Technical Context

**Language/Version**: TypeScript (ESM), Node 22  
**Primary Dependencies**: Fastify, Prisma, Vitest, React 19 + Mantine (`admin-ui`)  
**Storage**: PostgreSQL — extend `CuentaGlobal` (`deprecatedAt`, `reportRole`); reuse `AdminAuditLog`  
**Testing**: Vitest unit + integration (`backend/tests/`); TDD required  
**Target Platform**: Linux server + admin SPA (desktop-first)  
**Project Type**: Monorepo web service + admin SPA  
**Performance Goals**: SC-001 — subtree ≤50 nodes apply < 3s local  
**Constraints**: Clean Architecture; no journal FK rewrite; fail closed on cross-class; admin RBAC from 013  
**Scale/Scope**: ~100–200 global accounts; single live chart; operator count small
